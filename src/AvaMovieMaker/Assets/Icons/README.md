# Icons

Toolbar, menu and dialog icons and the app icon from the Windows XP High Resolution Icon Pack by marchmountain,
release 02 (https://github.com/marchmountain/-Windows-XP-High-Resolution-Icon-Pack/releases/tag/02).
The pack is under CC0 1.0 (`LICENSE-CC0.txt`).

Each icon is the pack's 1024×1024 PNG scaled down (Lanczos) to 16, 24, 32, 48 and 64 px, saved as
`<kind>-<size>.png`. `Glyph` picks the smallest size that covers the display size at the screen's scaling.

| Kind | Pack icon |
|---|---|
| `import` | WMP Import Video |
| `undo`, `redo` | Undo, Redo |
| `automovie` | Wizard |
| `publish` | Write Files to Disc |
| `tasks` | Checklist |
| `collections` | Folder Closed |
| `view-options` | Thumbnail View |
| `split` | Cut |
| `audio-from-video`, `audio-music` | Generic Video, Generic Audio |
| `wizard-back` | Back |
| `computer` | My Computer |
| `dvd`, `cd` | DVD, CD-R |
| `email` | Email |
| `camera` | Camcorder |
| `narrate` | Narrator |
| `audio-levels` | Volume Level |
| `app` | Windows Movie Maker |

The pack has no match for the transport buttons, zoom in and out, the effect star, text alignment and size, expand and
collapse, the split-button arrow or Transitions. `Glyph` still draws those as vector paths.

The same Windows Movie Maker PNG, scaled to 512 px, is `tools/icons/icon-512.png`, which the Linux, macOS and Windows
packages (`tools/windows/AvaMovieMaker.ico`) take their icons from.
